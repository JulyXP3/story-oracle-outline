# 故事神谕·大纲版（story-oracle-outline）

这是 [故事神谕](https://github.com/namelessone88/story-oracle) 的独立二创扩展，用于根据角色设定、故事上下文和自选模板生成剧情大纲，再将大纲写入世界书作为剧情指导。

**需要同时安装故事神谕本体，本扩展不能独立运行。** 已获原作者 **namelessone88** 授权二改，**禁止商业化**。本项目仅维护二创部分，不打包、不优化本体源码。

## 安装与依赖

1. 在 SillyTavern 中安装并启用 [故事神谕本体](https://github.com/namelessone88/story-oracle)。本扩展要求本体 **≥ 1.22.0**、提供 **StoryOracleAPI v1**；最低依赖不等于所有后续版本均已完整回归。
2. 在酒馆的扩展管理中选择“安装扩展”，填写本仓库地址：

   ```text
   https://github.com/JulyXP3/story-oracle-outline
   ```

3. 刷新酒馆页面，打开故事神谕，确认出现“大纲”模式。
4. 世界书注入功能需要提供相应公开读写接口的 **TavernHelper／酒馆助手**。模板管理和模板存储本身不依赖这些世界书接口。

模型连接、模型选择、流式输出和连接预设由故事神谕本体管理。本扩展不单独保存 API 密钥，也不提供另一套模型连接层。

## 基本使用（1.6.2）

1. 打开需要规划剧情的角色聊天，进入故事神谕的“大纲”模式。
2. 选择“大纲模板预设”。需要自定义时，打开“管理模板”，新建或修改模板；可导入、导出 `.txt` 文件。
3. 输入本次大纲要求并发送，模型按当前模板填充内容。模板的首尾标签应保留，注入功能会根据模板识别标签，而不是固定使用某一种标签名。
4. 查看回复后可使用“编辑”，或在模型漏标签时使用“标签补充（仅限最新一楼）”。
5. 使用回复上的“注入剧情大纲”，将大纲写入当前角色的 `<角色名>-剧情指导` 世界书。

### 上下文与可选项

- **酒馆故事正文**：角色聊天中的故事内容，按本体的上下文设置读取。
- **大纲对话历史**：大纲模式中的历次提问和回复，与酒馆故事正文是两个来源。1.6.2 中勾选项名为“发送全量大纲聊天记录”；不勾选时，只发送本轮大纲输入，不附带旧的大纲问答，故事上下文照常组装。
- **世界书剧情指导**：1.6.2 默认排除本插件的剧情指导内容，避免旧规划干扰下一次生成。主动附带已启用大纲的选项属于下方未发布改动。
- **套用补全预设**：跟随本体选择。自定义预设使用已保存的策展快照，保留消息角色和顺序；只选择预设名称但未保存策展时，按未启用处理。内置破限使用本体对应选项及其开关。
- **MVU 实时变量**：有可用 MVU 数据时，可附带 `stat_data`；跟随本体“带上实时变量状态”设置，非 MVU 角色省略。

### 世界书注入

目标书名为 `<角色名>-剧情指导`，条目按 `剧情指导`、`剧情指导2` 等命名。注入时可根据现有条目选择新建或覆盖；新建的剧情指导设为启用，后续新建会停用此前启用的剧情指导条目。

生成、编辑和注入是不同操作。生成回复不会自动写入世界书；注入后应检查目标条目正文与启用状态。角色同名、改名或第三方修改世界书可能影响按角色名称定位，不要把辅助接口回读等同于跨设备事务保证。

## 大纲模板存储（1.6.0 起）

### 三层存储

| 层级 | 位置 | 说明 |
|---|---|---|
| 服务端（主层） | 酒馆数据目录 `data/<用户>/user/files/so-outline-tpl-*.txt`；索引 `so-outline-tpl-index.json`，并镜像到设置的 `extensionSettings.storyOracleOutlineTemplates` | 同一酒馆数据可供不同浏览器使用；采用酒馆 `/api/files` 接口 |
| IndexedDB（降级） | 当前浏览器数据库 `story_oracle_outline` | 服务端不可用时使用；数据仅在该浏览器中 |
| localStorage（兜底） | 当前浏览器键 `so_outline_templates` | 最后一层及旧版兼容备份，受浏览器配额限制 |

索引文件是模板列表的权威来源。单独依赖 `settings.json` 的镜像会被其他酒馆窗口的整份设置保存覆盖，因此还保留独立索引文件。

**模板保存、读取、导入、导出本身不调用模型、不消耗模型 token。** 模板内容在生成时被发送给模型，则会占用上下文并产生正常模型调用费用。

服务端失败时自动尝试 IndexedDB、localStorage。浏览器降级保存不等于已经同步到服务端；换浏览器、清除站点数据或迁移酒馆前，建议先导出重要模板备份。不承诺多标签页或多设备同时编辑的强一致。

### 导入、导出与删除

- `.txt` 导入支持多文件；文件名作为模板名，全文作为模板正文。同名模板使用后缀区分，不覆盖已有模板。
- 导出生成 `.txt`，可在另一浏览器或酒馆重新导入。
- 删除请优先使用“管理模板”中的“删除”，不要根据宽泛文件名前缀直接清空酒馆文件目录。
- **删除旧文件的行为有版本区别**：已提交 1.6.2 尝试清理旧正文文件；下方未发布的 A 轮为避免误删，改为只更新索引、旧正文暂留。未发布工作树可能因此增加磁盘占用，不能按旧记录声称“不留孤儿文件”。

## 常见问题

### 没有“大纲”按钮

先确认本体与本扩展都已启用，再刷新页面。本体需要暴露兼容的 StoryOracleAPI；仅安装本扩展不会出现完整功能。升级本体后如发生异常，可提供版本、操作步骤和经过脱敏的错误信息，不要公开 API 密钥、认证头、设置备份或完整私人请求。

### 为什么模板在另一个浏览器里找不到？

模板可能降级到了当前浏览器的 IndexedDB／localStorage，并未保存到服务端。先在原浏览器导出，再到目标浏览器导入；清除浏览器站点数据前务必备份。

### 为什么原有剧情指导没有自动带进新大纲？

1.6.2 默认排除剧情指导，减少旧规划干扰。主动附带已启用条目的开关尚属于上述未发布适配，不是 1.6.2 原有能力。

### 为什么菜单能打开，却不代表大纲模式已完整支持？

大纲有独立的提示词组装和聊天房间。原生菜单可见不等于所有发送侧逻辑已接入；不要仅依据本体版本号宣称全菜单兼容。上述未发布适配只接入两项楼层工具，其余三项仅隐藏入口。
